# Installation

1. Clone the repository using `git clone https://github.com/username/nodeWaveEngine.git`.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Build the Docker image using `docker build -t node-wave-engine .`.
4. Run the container using `docker run -p 8080:8080 node-wave-engine`.
